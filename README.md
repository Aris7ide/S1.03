# Tarea S1.03 - Java Collections

## 📌 Enunciat del exercici
En esta tarea trabajaremos los conceptos fundamentales de las colecciones en Java, poniendo especial atención a las clases más comunes de la librería java.util, tales como ArrayList, HashSet, HashMapy ListIterator.

El objetivo es reforzar tu comprensión sobre cómo se crean, modifican y recorren estas estructuras de datos, así como ver su comportamiento frente a situaciones como la gestión de duplicados, la comparación de objetos o la manipulación del orden de elementos. También pondrás en práctica la lectura y escritura de archivos, así como la interacción con el usuario.

Todo ello te permitirá desarrollar pequeños programas que combinen diversas colecciones de forma práctica, clara y bien estructurada.

Recomendaciones generales

- Use IntelliJ para todos los ejercicios.
- Sigue las buenas prácticas indicadas en el Sprint 0 para garantizar la calidad del código y de las entregas.
- Puedes utilizar proyectos Java sencillos, Maven o Gradle.
- Escribe el código en inglés.
- Además de practicar con colecciones, esta tarea es una oportunidad para mejorar la organización de tu código . Separa responsabilidades en métodos y clases, evita escribir toda la lógica dentro del mainy piensa en el diseño antes de implementarlo.
